# Herbal Store

## Outcome

Build a new Herbal branded, responsive online storefront in Laravel/PHP, guided by the
provided Figma home and all-products compositions.

## Actors and workflows

- Shopper: browse the home page and catalog, search and filter products, inspect a product,
  add items to a session cart, and adjust or remove cart quantities.
- Store operator: replace the development catalog with approved Herbal products before
  production. A catalog administration interface is not in this phase.

## Stack

Laravel 13, PHP 8.5, Blade, CSS and small vanilla JavaScript interactions; SQLite locally.
Checkout and a live payment provider are not part of the approved first phase.

## Scope boundary

The Figma file provides desktop Home Page and ALL Products frames. Implement those pages and
adapt them for smaller viewports. Storefront products currently come from explicitly marked
demo seed data based on the Figma catalog; no live Herbal inventory has been provided.
